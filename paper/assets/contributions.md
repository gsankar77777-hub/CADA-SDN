# Research Contributions

The primary contributions of this research are summarized as follows:

1. A novel Adaptive Context-Aware Risk Assessment (ACARA) framework is proposed for detecting and assessing DDoS attacks in Software-Defined Networking (SDN) environments.

2. A context-dependent adaptive feature weighting mechanism is introduced, enabling the framework to dynamically adjust the importance of traffic features according to the detected traffic context.

3. A risk-based mitigation recommendation module is developed to generate appropriate mitigation actions based on the computed adaptive risk level.

4. The proposed framework is experimentally validated using both the publicly available CIC-DDoS2019 dataset and a self-generated SDN dataset containing Normal, TCP SYN Flood, UDP Flood, and ICMP Flood traffic scenarios.
